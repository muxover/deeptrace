# DeepTrace v0.2.0 — Tracers fixed, plugin install

**Release date:** 2026-09-28

### Install

```bash
git clone --branch v0.2.0 https://github.com/muxover/deeptrace.git
cp -r deeptrace/skills/deeptrace ~/.claude/skills/deeptrace
```

---

## Summary

Every tool was run against real projects and the failures were fixed, so traces and timings can be trusted. DeepTrace also installs as a Claude Code plugin.

---

## What's included

### Claude Code plugin

- Plugin and marketplace manifests for `/plugin` install
- The skill calls its tools through `${CLAUDE_SKILL_DIR}`, so they resolve from any project

### Tools

- `trace-http.py --repeat N --concurrency C` fires requests in parallel for race and idempotency checks
- `trace.py` labels every exception caught, uncaught, or exit, records return values, and traces modules with `-m`
- `trace-ui.py` adds screenshots, console source locations, and page error stacks
- `trace-go.py` prints call counts and goroutines; `trace-rust.py` prints flamegraph hot frames as text
- `run.py` passes arguments after `--`, trims output, and ends with a summary
- The skill adds a verify-the-fix step

---

## Fixed

- UI network timings were wrong, and the UI tracer crashed when a page failed to load
- The Go tracer's default traced every function and broke the run
- The Rust tracer passed its own flags to the program, and `--unit-test` ran the binary
- `run.py` misdetected yarn and bun, ran missing Make targets, and left processes running after a timeout
- `trace.py` traced sibling directories and lost the exit code
- `recon.py` counted every `DEBUG` as a `BUG` marker
