**Release date:** 2026-06-25

### Install

```bash
git clone --branch v0.1.0 https://github.com/muxover/deeptrace.git
cp -r deeptrace/skills/deeptrace ~/.claude/skills/deeptrace
```

---

## Summary

First release of DeepTrace: a skill that makes an AI agent map a project, run it, and trace what actually executes before it reports bugs, with every finding tied to a real location.

---

## What's included

### The skill

- Six levels of analysis, from direct logic down to real-world failure simulation
- Step-by-step execution simulation: inputs, state changes, output, and failure points
- Security, performance, API, and UI domain lenses
- A fixed report format with severities and a confidence score

### Toolkit

- `recon.py` maps stacks, languages, entry points, hotspots, and TODO/FIXME markers
- `run.py` detects and runs tests, builds, or the app, capturing output and exit codes
- Runtime tracers for Python, Node, Go, and Rust, plus live HTTP and browser UI tracers

### Examples

- Five worked analyses: a race condition, SQL injection, an N+1 query, a React stale closure, and a double-charge on retry
