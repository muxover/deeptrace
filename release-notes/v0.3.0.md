# DeepTrace v0.3.0 — Install in every agent

**Release date:** 2026-09-28

### Install

```bash
git clone --branch v0.3.0 https://github.com/muxover/deeptrace.git
cp -r deeptrace/skills/deeptrace ~/.claude/skills/deeptrace
```

---

## Summary

DeepTrace installs as a plugin in Claude Code, Codex, and Cursor, and in any other skills-aware agent with one `npx skills add` command. Node profiling moves to Node's built-in profiler, which handles every case the bundled tracer missed.

---

## What's included

### Install anywhere

- Codex plugin and marketplace: `codex plugin marketplace add muxover/deeptrace`
- Cursor plugin and marketplace for **Customize → From GitHub Repository**
- `npx skills add muxover/deeptrace` for Copilot, Gemini CLI, Windsurf, and other agents
- The Claude Code marketplace is now named `deeptrace`: install with `deeptrace@deeptrace`

### Node profiling

- The skill profiles Node, JavaScript, and TypeScript with `node --cpu-prof`, which also covers `process.exit()`, ES modules with top-level `await`, and `tsx`
- `reference.md` explains how to read the `.cpuprofile` it writes

### Releases

- Every version has release notes and a GitHub release, created by a release workflow that runs CI first

### Removed

- `trace-node.js`, replaced by Node's built-in profiler
